How the Wall Chooses

Once a minute, the controller picks the next clip for the wall. This page shows how it makes that choice and how it learns from the audience during the day.

Safeguards

  • ConfirmationAfter sending a clip, the controller checks with Resolume that it is playing, allowing 2 seconds. If a different clip is playing, it sends the clip once more. If Resolume can't be reached to check, the controller assumes the clip is playing.
  • Failed clipIf the clip still isn't confirmed, the controller keeps its record of the wall where it was and doesn't score the clip. The next minute's move is planned from that position.
  • Lost dataIf no new crowd data arrives for 30 seconds, the controller stops following the room. It moves the wall down one ring per clip along its current arm until it reaches Barren or the data comes back.
  • MidnightThe personality changes and the estimates return to its starting values. The action bonus is cleared, and the clip playing at midnight is not scored.
